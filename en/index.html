SEC.02 // FEATURES

A command post, anywhere

Desktop, tablet or browser — the same map, in real time, for the whole team.

MAP

Real-time tactical map

Markers, zones and GPS positions shared instantly across every connected operator — the same tactical picture, for everyone, down to the second.

E2E

End-to-end encrypted chat

Messages encrypted with AES-256-GCM on the client side. Neither the server nor a third party can read them.

RF

Off-grid radio

LoRa Meshtastic communication at 868 MHz — coordination continues even without 4G or internet.

FBK

Automatic failover

Network loss detected within 30 seconds. Automatic switch to radio and local cache.

SOS

MAYDAY alert

One button to trigger a priority alert, instantly visible to the whole team.

OS

Cross-platform

Desktop app (Mac / Windows / Linux) and a web client optimized for Android phones and tablets, or any browser.

STA

Live status

Every point (clear, active, danger, secured, evacuated, blocked) updates in one click.

VOX

Encrypted voice messages

Send a voice message straight in the chat, encrypted like everything else — available over 4G/5G. Text still gets through even over off-grid radio.

LOG

Logistics tracking

Every unit tracks its own inventory — vehicles, personnel, supplies — with automatic low-stock alerts. A consolidated view for the command post, plus resupply request handling.

LYR

Planning layers

Draft a plan on a separate layer — markers, zones — without touching the live operation. Delegate it to a subordinate to plan their part, then activate it to merge it in live.

ISO

Per-operation isolation & multi-node continuity

Every mission — and every client — has its own space, never shared. Multiple command posts stay continuously in sync; if one goes down, devices automatically switch to another in under 30 seconds, with no data loss.

SEC.04 // SECURITY

Security by design

Seven layers of protection, from the radio to message encryption.

  • Network — proxy/CDN, HTTPS TLS 1.3
  • Authentication — password, session, brute-force lockout
  • Transport — AES-256 encryption on real-time links
  • Storage — encrypted database (SQLCipher AES-256)
  • Radio — AES-256-CTR at the Meshtastic firmware level
  • Chat — end-to-end AES-256-GCM encryption
  • Infrastructure — a separate server and database per client, never shared
🇨🇭

Data governed by Swiss law

Hosted on Infomaniak infrastructure, datacenters in Geneva and Winterthur. No client data ever leaves Switzerland.
